# Статус проверки первой версии

Дата: 26 октября 2026 года.

## Успешно выполнено

- Установка зафиксированных Python и Node зависимостей.
- `npm run build`: production-сборка Next.js 16.4.3, включая TypeScript.
- `npm run typecheck`.
- `npm run smoke`: реальный Next.js production server с тестовым HTTP API.
  Проверены SSR товара, свежие данные при следующем запросе, пустой поиск,
  отдельное сообщение ошибки API и заголовок `no-store`.
- `python -m pytest -q`: **18 passed, 16 skipped**. Без внешней БД выполнены тесты
  логики бота, allowlist, Mini App-кнопки, валидации фото/названия, ограничения буфера,
  авторизации HTTP, JSON и webhook secret.
- Python-модули скомпилированы; синтаксис Compose YAML разобран.
- MinIO из release `RELEASE.2025-10-15T17-29-55Z` успешно собран через Go 1.25.3.

## Пока не подтверждено

- **16 PostgreSQL integration tests не выполнены на нативном PostgreSQL.** Они есть
  в исходниках и в CI, но эта среда не предоставляет Docker и не позволяет обычный
  запуск PostgreSQL под отдельным пользователем. Дополнительная попытка через
  PostgreSQL/WASM socket не завершилась успешно и не считается пройденной проверкой.
- Запуск всего `docker compose up` и работа двух контейнерных реплик.
- Работа с настоящим MinIO: бинарник собран, но его запуск в этой среде блокируется
  ограничением системного вызова для перечисления сетевых интерфейсов.
- Живая доставка сообщений Telegram, скачивание фото, регистрация webhook и Mini App:
  пользовательский токен и публичный HTTPS-адрес не предоставлены.
- Визуальная проверка в браузере: браузерный runtime недоступен; выполнены сборка,
  TypeScript и HTTP-проверки SSR. Адаптивная CSS-разметка требует проверки на устройстве.
- Публичный деплой и GitHub-репозиторий не созданы.

## Следующая обязательная проверка на компьютере пользователя

```powershell
python scripts/setup_env.py
docker compose up -d --build
docker compose --profile test build tests
docker compose --profile test run --rm tests
docker compose up -d --scale api=2 --scale bot=2 --scale web=2
```

Затем настройте `.env` и HTTPS по README, зарегистрируйте webhook и пройдите сценарий
добавления товара через настоящий Telegram. Не считайте этот архив уже проверенным
готовым результатом для сдачи без этих шагов.
